- Learnings:
  - Interpretation of ADR-0005 layer 2: outside `examples/` only currency amounts are flagged (percentages are legitimate in CSS and guidelines); inside `examples/` any amount or percentage needs the marker. Marker is `mq:illustrative`, valid on the same line or, in the first five lines, for the whole file. Deny-list, hosts, paths and metadata are never exempted by it.
  - Plan ruling 8 cites `CHF 2'460'000` as a format example; it now carries `<!-- mq:illustrative -->`. Increment 09's `guidelines/data-patterns.md` will need the same marker (file header) for its format examples.
  - Exclusion list is `scripts/confidentiality-exclude.txt`, exact paths only; a listed path missing from the tree makes the scanner exit 2. Files come from `git ls-files --cached --others --exclude-standard`, so untracked new files are scanned too.
  - Tests must never name a deny-list term literally (the real-tree run uses the fixture deny-list); the path test builds its term from the loaded list.
  - Image metadata policy: PNG tEXt/iTXt/zTXt/eXIf and JPEG APP1 (EXIF/XMP)/APP13 (IPTC) are flagged. The brand PNGs carry only a tIME chunk, which is allowed. ICO files are not parsed.
  - Dotfiles: gitleaks is already declared in `dot_mise.toml` (`gitleaks = "latest"`); no dotfiles change needed. The repo's mise.toml pins 8.30.1 exactly.
  - Exit codes: 0 clean, 1 findings, 2 misconfigured (no deny-list in CI, missing deny-list file, stale exclusion).
