Build a sober data table for a MedQuantis app listing six fictitious medicines (Médicament A to F) with their price-model status: published, draft or error. Use a status dot followed by the word, flag only the rows that need attention, and let the table scroll horizontally on narrow screens. Save it as output.html in the current directory.
